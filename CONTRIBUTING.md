# Contributing to PrintLead CRM

Thank you for your interest in contributing to PrintLead CRM.

## How to contribute

1. Fork the repository.
2. Create a new branch for your changes.
3. Make your improvements.
4. Submit a Pull Request.

## Development guidelines

- Keep the code clean and documented.
- Write clear commit messages.
- Test changes before submitting a Pull Request.
- Focus on improving usability for print shops and sign-making businesses.

## Reporting issues

If you find a bug or have an idea for a new feature, please create an Issue describing:

- The problem or suggestion.
- Steps to reproduce it.
- Possible improvements.

Thank you for helping improve PrintLead CRM!
