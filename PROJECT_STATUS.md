# PrintLead CRM - Project Status

## Current Version

v0.1.0

## Overview

PrintLead CRM is an open-source CRM project focused on the needs of small print shops, sign makers and graphic communication businesses.

## Current Features

✅ Project architecture  
✅ Backend API  
✅ Customer database  
✅ Customer management endpoints  
✅ React frontend  
✅ Customer registration interface  
✅ Documentation system  

## Development Goals

The next development stages focus on:

- Improving the user interface.
- Adding quote management.
- Adding production workflow.
- Creating dashboards and business analytics.
- Improving usability for small businesses.

## Project Vision

The goal of PrintLead CRM is to create an accessible and specialized business management tool for companies in the printing and visual communication sector.
